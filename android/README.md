# vLabeler для Android

Порт [vLabeler](https://github.com/sdercolin/vlabeler) (Compose Desktop) на Android с сохранением максимума функций.
Весь основной код приложения (≈43 тыс. строк: модели, парсеры, лейблеры, плагины, редактор, диалоги) берётся **напрямую**
из `../src/jvmMain` без копирования — Android-модуль только подменяет платформенные части.

## Сборка

Требуется Android Studio (или JDK 17+ и Android SDK 34).

1. Откройте папку `android/` в Android Studio (не корень репозитория).
2. Дождитесь Gradle Sync.
3. `Run ▶` — установка на устройство/эмулятор, или `Build → Assemble Project` — APK появятся в
   `android/app/build/outputs/apk/{debug,release}/`.

Командная строка: `cd android && ./gradlew assembleRelease` (Windows: `gradlew.bat assembleRelease`).

Release-сборка подписывается debug-ключом (для личного использования). Для публикации добавьте свой `signingConfig`.

## Как устроен порт

| Механизм | Где | Что делает |
|---|---|---|
| Общий код | `app/build.gradle.kts` → задача `prepareSharedSources` | Копирует `src/jvmMain/kotlin` в `build/generated/shared`, исключая файлы из `excludedSharedFiles` |
| Переназначение импортов | `importRemaps` | `java.awt.*` → `android.compat.awt.*`, Apache HTTP → OkHttp, `@Preview` desktop → Android и т.п. |
| Точечные патчи | `sharedPatches`, `globalPatches` | Небольшие текстовые правки (PNG через `Bitmap.compress`, `LogRecord.instant`, радиус попадания по маркерам для пальца, отключение авто-обновления…). Сборка падает, если патч не нашёл своё место — так сразу видно, что upstream изменился |
| Шимы desktop-API Compose | `app/src/main/kotlin/androidx/...`, `org/jetbrains/...` | `DialogWindow`, `MenuBar`, `KeyShortcut`, `onPointerEvent`, `PointerButton`, `VerticalScrollbar`, `TooltipArea`, `ContextMenuArea`, `painterResource(String)`, `useResource`, SplitPane, Skia-битмапы, `Font(data)` |
| Java Sound | `app/src/main/kotlin/javax/sound/sampled` | Своя реализация `AudioSystem`/`AudioFormat`/`AudioInputStream`/`SourceDataLine`: чтение WAV (8/16/24/32 бит, float, extensible, RF64), конвертация и ресэмплинг, воспроизведение через `AudioTrack` |
| Замены файлов | `app/src/main/kotlin/com/sdercolin/vlabeler/...` | Файлы с теми же путями, что и в desktop-версии: `Main.kt`, `JavaScript.kt`, `Keyboard.kt`, `FileDialog.kt`, видео, кодировки и т.д. |

## Управление на сенсорном экране

* **Один палец = мышь**: тап — клик, перетаскивание маркеров, инструменты (курсор, ножницы, панорама, воспроизведение).
  Радиус попадания по линиям маркеров увеличен для пальца.
* **Два пальца на графике**: сдвиг — прокрутка по времени, щипок — масштаб (разрешение).
* **Долгое нажатие** — контекстное меню (например, в списке записей).
* **Верхняя панель**: ☰ — всё меню desktop-версии (File/Edit/View/Navigate/Tools/Settings/Help),
  «UI …» — масштаб интерфейса (Auto/100…60 %), сохранить, отменить/повторить, предыдущая/следующая запись,
  воспроизвести, масштаб, и «залипающие» модификаторы **Ctrl / Shift / Alt / RMB** — они комбинируются с касаниями,
  поэтому доступны все действия мыши из раскладки (например, Ctrl+клик, воспроизведение правой кнопкой = RMB + тап).
  В списке записей Ctrl + тап добавляет запись к множественному выбору, Shift + тап выбирает диапазон.
* Полоса прокрутки: тап по дорожке — переход, перетаскивание ползунка.
* **Аппаратная клавиатура** поддерживается полностью: все горячие клавиши и пункты меню работают как на ПК.
* «Назад» закрывает диалоги, а на главном экране — выход (с предложением сохранить).

## Файлы и папки

При первом запуске приложение просит доступ «Ко всем файлам» (как настольное приложение, vLabeler работает с путями
к папкам сэмплов и файлам oto.ini/lab). После этого:

* папка приложения — `/storage/emulated/0/vLabeler` (настройки, пользовательские лейблеры и плагины, логи
  `.logs/error.log`) — её можно открыть любым файловым менеджером и класть туда свои лейблеры/плагины, как на ПК;
* проекты и сэмплы — в любой папке памяти устройства.

Без разрешения приложение работает только в своей папке `Android/data/com.sdercolin.vlabeler/files`.

## Что отличается от desktop-версии

* Интеграция с UTAU через IPC (плагин-мост) — недоступна: UTAU не работает на Android.
* Отправка анонимной статистики отключена.
* «Проверить обновления» открывает страницу релизов (desktop-установщики на Android не нужны).
* Пользовательские курсоры инструментов и всплывающие подсказки при наведении отсутствуют (нет мыши).
* Пути к FFmpeg в настройках игнорируются — используется встроенный декодер Android.
* Окна-диалоги desktop открываются как модальные окна поверх приложения, размер ограничен экраном.
* Рекомендуется планшет или телефон в альбомной ориентации (приложение закреплено в альбомной ориентации).

## Обновление из upstream

```
git pull upstream dev
cd android && ./gradlew assembleDebug
```

Если в upstream изменился файл из `sharedPatches` так, что патч больше не применяется, сборка остановится с понятной
ошибкой `Patch target not found in …` — достаточно поправить соответствующую строку в `app/build.gradle.kts`.

## Проверено

На эмуляторе Android 17 (API 37): запуск, выдача доступа к файлам, мастер создания проекта, встроенный файловый
браузер, загрузка лейблеров (скрипты QuickJS), разбор oto.ini, построение волны и спектрограммы (16 бит моно и
24 бит стерео), воспроизведение, меню, отметки ★/✓, сохранение/открытие проекта, диалоги плагинов, масштаб UI, выход.

Не проверено на эмуляторе (им можно было управлять только одиночными кликами): перетаскивание маркеров пальцем,
жесты двумя пальцами, ввод текста с экранной клавиатуры. Логика этих функций реализована, но стоит проверить на
реальном устройстве.
